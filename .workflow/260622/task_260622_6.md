# План рефакторинга: Смешение слоёв (UI и логика)

## Проблема

`proxyRoute.js` — модуль маршрутизации — напрямую импортирует UI-функции из
`ui.js`:

```js
import { addHostToTab, setTabIconProxied, tabUrlsCache } from './ui.js';
```

Это создаёт три проблемы:
1. **Маршрутизация зависит от UI** — при тестировании `handleProxyRequest`
   нужно мокать `ui.js`
2. **Нарушение единой ответственности** — `proxyRoute.js` должен только
   решать, через какой прокси пустить запрос, а не обновлять бейджи
3. **Скрытая связность** — чтобы понять полный поток, нужно читать 3 файла

## План

### Фаза: Передать колбэки в `handleProxyRequest` из `main.js`

**Идея:** `proxyRoute.js` не импортирует UI вообще. Вместо этого
`handleProxyRequest(details)` принимает второй аргумент — объект-контекст
с колбэками:

```js
handleProxyRequest(details, {
    getTabUrl(tabId) { ... },     // доступ к tabUrlsCache
    onProxyMatch(tabId, host) { ... } // обновление UI
})
```

`main.js` создаёт этот контекст, передавая реальные функции из `ui.js`.

### Изменения в файлах

#### `src/background/proxyRoute.js`

```js
// Было:
import { addHostToTab, setTabIconProxied, tabUrlsCache } from './ui.js';

// Стало:
// (никаких импортов из ui.js)
export function handleProxyRequest(details, { getTabUrl, onProxyMatch } = {}) {
    // ...
    // Вместо tabUrlsCache.get(tabId):
    const currentTabUrlStr = getTabUrl ? getTabUrl(details.tabId) : null;
    // ...
    // Вместо addHostToTab + setTabIconProxied:
    if (details.tabId !== -1 && onProxyMatch) {
        onProxyMatch(details.tabId, url.hostname);
    }
    // ...
}
```

#### `src/background/main.js`

```js
import { addHostToTab, setTabIconProxied, tabUrlsCache } from './ui.js';

// Было:
browser.proxy.onRequest.addListener(handleProxyRequest, ...);

// Стало:
browser.proxy.onRequest.addListener(
    (details) => handleProxyRequest(details, {
        getTabUrl: (tabId) => tabUrlsCache.get(tabId),
        onProxyMatch: (tabId, hostname) => {
            addHostToTab(tabId, hostname);
            setTabIconProxied(tabId);
        }
    }),
    { urls: ["<all_urls>"] }
);
```

### Что остаётся без изменений

- `ui.js` — `tabUrlsCache`, `addHostToTab`, `setTabIconProxied` остаются
  там же; main.js сам передаёт их как колбэки
- `state.js` — `state` по-прежнему импортируется в `proxyRoute.js` (это
  данные, не UI)
