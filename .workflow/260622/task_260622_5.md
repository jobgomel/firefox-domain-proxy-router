# План рефакторинга: Обработка ошибок

## Проблемы

### 1. `decodeURIComponent` без try/catch (options.js:388–391)

```js
if (user && pass) {
    document.getElementById('p-user').value = decodeURIComponent(user);
    document.getElementById('p-pass').value = decodeURIComponent(pass);
}
```

При вводе в поле Host некорректной percent-строки (например, `%ZZ` или `%GG`)
`decodeURIComponent` выбрасывает `URIError`. Это прерывает автопарсинг
и оставляет пользователя без обратной связи.

### 2. `fetchPublicProxies` — ошибки скрыты (options.js:540–570)

Текущая обработка:
- `try/catch` ловит и сетевые ошибки, и HTTP-статусы
- Показывает `❌ Ошибка загрузки списка: ${err.message}`
- Нет проверки `navigator.onLine` — пользователь не видит, проблема в нём
  или на сервере
- Нет кнопки повторной попытки в сообщении об ошибке

## План

### Фаза 1: Безопасное декодирование URI

Выделить функцию `safeDecodeURIComponent` и заменить прямые вызовы:

```js
function safeDecodeURIComponent(str) {
    try {
        return decodeURIComponent(str);
    } catch (e) {
        // Некорректная percent-строка — возвращаем как есть
        return str;
    }
}
```

**Изменяемые файлы:**
- `src/options/options.js` — обернуть оба вызова decodeURIComponent

### Фаза 2: Улучшить обработку ошибок fetchPublicProxies

Добавить:
- Проверку `navigator.onLine` — сообщать, что нет соединения
- Кнопку «Повторить» в блоке с ошибкой
- Различать HTTP-ошибки (сервер) и сетевые (клиент) в сообщении

```js
async function fetchPublicProxies() {
    pubListContainer.innerHTML = '';
    pubLoading.style.display = 'block';
    try {
        if (!navigator.onLine) {
            throw new Error('Нет подключения к интернету. Проверьте соединение.');
        }
        const res = await fetch(URL, { cache: 'no-store' });
        if (!res.ok) throw new Error(`Ошибка сервера (HTTP ${res.status})`);
        const data = await res.json();
        // ... успех
    } catch (err) {
        pubListContainer.replaceChildren(createErrorElement(err.message, fetchPublicProxies));
    } finally {
        pubLoading.style.display = 'none';
    }
}

function createErrorElement(message, retryFn) {
    const container = document.createElement('div');
    container.style.cssText = 'text-align:center; padding:1rem;';

    const msgEl = document.createElement('div');
    msgEl.style.cssText = 'color:#dc2626; margin-bottom:0.75rem;';
    msgEl.textContent = `❌ ${message}`;
    container.appendChild(msgEl);

    if (retryFn) {
        const retryBtn = document.createElement('button');
        retryBtn.className = 'btn-test';
        retryBtn.textContent = '↻ Повторить';
        retryBtn.addEventListener('click', retryFn);
        container.appendChild(retryBtn);
    }

    return container;
}
```

**Изменяемые файлы:**
- `src/options/options.js` — заменить `fetchPublicProxies`
