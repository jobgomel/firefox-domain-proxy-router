# План рефакторинга: Чистота кода в options.js (и popup.js)

## Проблемы

### 1. options.js — 780 строк без четкой структуры

Текущий порядок кода хаотичен:

| Строки | Что | Проблема |
|--------|-----|----------|
| 1–5 | Импорты + state | ОК |
| 7 | `genId` | Утилита, но в начале файла |
| 9–34 | `setThemeToggle`, `setPlaceholder`, `setSelectPlaceholder` | DOM-хелперы |
| 36–52 | `loadData()` | Инициализация |
| 54–84 | i18n, theme button, tab handlers | События |
| 86–318 | `renderAll`, `renderProxies`, `renderDomains`, `renderRules`, `updateRuleSelects` | Рендеры |
| 320–437 | Все action-обработчики (add/edit/delete/test/rule) | Экшены |
| **439** | **`loadData()`** | **Вызов в середине файла** |
| 441–478 | `p-host` авто-парсер | Обработчик |
| 480–504 | `btn-save-exceptions` | Обработчик |
| 506–530 | Экспорт | Обработчик |
| 532–584 | Импорт (fileInput, importBtn) | Обработчики |
| 586–780 | Публичные прокси (данные, ивенты, fetch, рендер) | Логика |

### 2. Длинные функции рендеринга

`renderProxies` (65 строк), `renderDomains` (50 строк), `renderRules` (63 строки),
`renderPublicProxies` (108 строк) — создают DOM-элементы inline, повторяя
одинаковые паттерны: `createElement('div')` + `className = 'card-row'`,
`controls-wrapper`, кнопки test/edit/delete и т.д.

### 3. popup.js — updateStatusText

Функции `updateStatusText` и `updateDescription` завязаны на переменные
`statusIcon`, `statusText`, `statusCard`, `modeDesc`, которые получены через
`getElementById` в начале `DOMContentLoaded`. Без HTML-контекста непонятно,
какие именно DOM-элементы стоят за этими ID.
