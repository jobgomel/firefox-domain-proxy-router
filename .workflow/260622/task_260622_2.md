# План рефакторинга: Работа с состоянием в options.js

## Проблема

В `options.js` (~872 строки, монолит) состояние хранится в голых глобальных
переменных (`appState`, `editingProxyId`, `editingDomainId`, `currentTab`).
Нет единой точки сохранения — `saveData()` вызывается в 5+ местах вручную,
а некоторые мутации обходят её полностью. `renderAll()` вызывается только
внутри `saveData()`, поэтому данные, изменённые без `saveData()`, не
отображаются.

### Найденные точки мутации (7 мест)

| # | Мутация | Было | Стало |
|---|---------|------|-------|
| 1 | btn-add-proxy | `appState.proxies[id]=...;saveData()` | `state.addProxy()|updateProxy()` |
| 2 | btn-add-domain | `appState.domains[id]=...;saveData()` | `state.addDomain()|updateDomain()` |
| 3 | btn-save-exceptions | `appState.exceptions=...;storage.local.set(...)` | `state.setExceptions()` |
| 4 | import JSON | 4 поля + `storage.local.set(...)` | `state.replaceAll()` |
| 5 | btnAdd публичных прокси | `appState.proxies[id]=...;saveData()` | `state.addProxy()` |
| 6 | deleteItem | `delete appState[type][id];saveData()` | `state.deleteProxy()|deleteDomain()` |
| 7 | deleteRule | `appState.rules.splice();saveData()` | `state.deleteRule()` |

## Что сделано

### Фаза 1: Создан `src/options/state.js` ✓

Модуль-класс `OptionsState` с инкапсулированными данными (`_data`),
методами-мутаторами, автоматическим сохранением в `browser.storage.local`
и колбэком рендера.

- Единый объект данных `_data = { proxies, domains, rules, exceptions }`
- UI-состояние: `_editing = { proxyId, domainId }`, `_currentTab`
- Каждый мутатор → `save()` → `renderFn()`
- `load()` с try/catch и дефолтными значениями
- `save()` с try/catch
- `validateDataStructure()` для импорта
- 10 методов-мутаторов: `addProxy`, `updateProxy`, `deleteProxy`,
  `addDomain`, `updateDomain`, `deleteDomain`, `addRule`, `deleteRule`,
  `setExceptions`, `replaceAll`

### Фаза 2: Отредактирован `src/options/options.js` ✓

- **Удалены**: глобальные `appState`, `editingProxyId`, `editingDomainId`, `currentTab`
- **Удалена**: функция `saveData()`
- **Добавлен**: `import { OptionsState } from './state.js'` + `const state = new OptionsState(renderAll)`
- **Исправлены** все 7 точек мутации (см. таблицу выше)
- **Исправлены**: `loadData()`, все render-функции, `updateRuleSelects()`, `testProxy()`, export
- `renderAll()` теперь вызывается автоматически после каждого `state.save()`

### Фаза 3: Без изменений в background

Background (`src/background/state.js`) продолжает слушать `storage.onChanged`.
После рефакторинга options пишет в storage через единый `state.save()` —
background подхватывает автоматически.

### Фаза 4: Обработка ошибок ✓

- try/catch в `load()` и `save()` в state.js
- `validateDataStructure()` перед `replaceAll()` (импорт)
- Значения по умолчанию при повреждённых данных в `load()`
