# План рефакторинга: Устранение дублирования кода

## Проблема

В проекте найдено 4 места с дублированием кода:

| # | Дубликат | Где | Количество копий |
|---|----------|-----|-----------------|
| 1 | `testProxy` — тестирование прокси через background | `options.js` (2 места) | 2 |

| 4 | `handleProxyAuth` — обработка авторизации прокси | `main.js` | 1 (изолирован) |

## План

### Фаза 1: Вынести `testProxy` в `src/shared/testProxy.js`

Общая функция, которая принимает `proxy` и `statusEl` и выполняет
тестирование через `browser.runtime.sendMessage({ action: 'testProxy', proxy })`.

```js
export async function testProxy(proxy, statusEl) {
    statusEl.textContent = "⌛ Ждем...";
    statusEl.style.color = "orange";
    try {
        const response = await browser.runtime.sendMessage({ action: 'testProxy', proxy });
        if (response && response.success) {
            statusEl.textContent = `✅ OK (${response.duration} ms)`;
            statusEl.style.color = "var(--text-success)";
        } else {
            statusEl.textContent = "❌ Ошибка";
            statusEl.style.color = "#991b1b";
        }
    } catch (e) {
        statusEl.textContent = "❌ Сбой";
        statusEl.style.color = "#991b1b";
    }
}
```

**Изменяемые файлы:**
- Создать: `src/shared/testProxy.js`
- Изменить: `src/options/options.js` (заменить оба места дублирования)

### Фаза 2: Вынести i18n в `src/shared/i18n.js`

Общая функция, которая проходит по всем `[data-i18n]` и устанавливает текст.

```js
export function applyI18n() {
    document.querySelectorAll('[data-i18n]').forEach(element => {
        const key = element.getAttribute('data-i18n');
        const translation = browser.i18n.getMessage(key);
        if (translation) {
            element.textContent = translation;
        }
    });
}
```

**Изменяемые файлы:**
- Создать: `src/shared/i18n.js`
- Изменить: `src/options/options.js` (заменить блок в DOMContentLoaded)
- Изменить: `src/popup/popup.js` (заменить блок в DOMContentLoaded)

### Фаза 4: Вынести `handleProxyAuth` в `src/background/auth.js`

Отдельный модуль с функцией, которая регистрирует слушатель `onAuthRequired`:

```js
// src/background/auth.js
import { state } from './state.js';

export function registerProxyAuthHandler() {
    browser.webRequest.onAuthRequired.addListener(
        handleProxyAuth,
        { urls: ["<all_urls>"] },
        ["blocking"]
    );
}

function handleProxyAuth(details) {
    if (!details.isProxy) return {};
    const proxyHost = details.challenger.host;
    const proxyPort = details.challenger.port;

    if (state.testProxyConfig && state.testProxyConfig.host === proxyHost
        && parseInt(state.testProxyConfig.port) === proxyPort) {
        return {
            authCredentials: {
                username: state.testProxyConfig.username,
                password: state.testProxyConfig.password
            }
        };
    }

    for (let key in state.proxies) {
        const authProxy = state.proxies[key];
        if (authProxy.host === proxyHost && parseInt(authProxy.port) === proxyPort) {
            if (authProxy.username && authProxy.password) {
                return {
                    authCredentials: {
                        username: authProxy.username,
                        password: authProxy.password
                    }
                };
            }
        }
    }
    return { cancel: true };
}
```

**Изменяемые файлы:**
- Создать: `src/background/auth.js`
- Изменить: `src/background/main.js` (заменить блок + импорт)
