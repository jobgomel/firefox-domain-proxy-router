# Proxy Router Manager

Универсальный и легковесный прокси-маршрутизатор для браузера Firefox (совместим с Manifest V3). Расширение позволяет гибко перенаправлять сетевой трафик для определенных доменов и масок путей через выбранные HTTP или SOCKS5 прокси-серверы, оставляя остальные запросы прямыми.

## 🚀 Основные возможности

* **Гибкое управление прокси:** Поддержка протоколов HTTP и SOCKS5 как в открытом режиме, так и с авторизацией по логину и паролю. Автоматический парсинг строк подключения формата `protocol://login:password@host:port`.
* **Умная маршрутизация по маскам:** Создание пользовательских групп доменов с поддержкой подстановочных знаков (`*`). Например: `*.example.com`, `site.com/app/*`. Каждой группе можно назначить свой прокси-сервер.
* **Списки исключений (Черный список):** Возможность задать глобальные маски для сайтов, которые всегда должны открываться напрямую, в обход любых прокси (например, локальные сети, государственные порталы).
* **Импорт из публичных источников:** Встроенный модуль загрузки бесплатных прокси (Free Proxy List) с возможностью мгновенного тестирования задержки (ping), фильтрацией по протоколам и странам/городам геолокации.
* **Резервное копирование:** Полный экспорт и импорт всей конфигурации (серверы, группы доменов, правила маршрутизации) в один клик через JSON-файл.
* **Интерактивный интерфейс:** Быстрое включение/выключение расширения через лаконичный Pop-up. Счетчик уникальных проксируемых хостов на текущей вкладке (бейдж) и индикация статуса активности (зеленый/серый).

## 🛠 Разработка и сборка

Проект использует **Gulp** для автоматизации процессов очистки, минификации кода и сборки готовых архивов для тестирования и публикации.

### Предварительные требования

Убедитесь, что у вас установлена платформа [Node.js](https://www.google.com/search?q=https://nodejs.org/) (рекомендуется LTS версия).

### Установка зависимостей

В корневого каталоге проекта выполните команду:

```bash
npm install

```

### Доступные сценарии сборки

* **Полная сборка (по умолчанию):**
```bash
npm run build

```


Очищает директорию `dist/`, создает сборку для тестирования (`dist/qa/`), сборку для публикации с минификацией ресурсов (`dist/prod/`), а также упаковывает их в zip-архивы `qa.zip` и `prod.zip`.
* **Сборка для тестирования (QA):**
```bash
npm run build:qa

```


Создает версию проекта без комментариев в коде, форматирует стили (`beautify`) для удобного анализа и сохраняет результат в `dist/qa/`.
* **Сборка для публикации (Production):**
```bash
npm run build:prod

```


Производит глубокую обфускацию и сжатие JavaScript через `terser`, минифицирует HTML/CSS ресурсы и формирует оптимизированный архив в `dist/prod/`.

## 📦 Установка в браузер

1. Откройте браузер **Firefox** и перейдите по адресу `about:debugging#/runtime-this-firefox`.
2. Нажмите кнопку **"Загрузить временное дополнение..."** (Load Temporary Add-on...).
3. Выберите файл `manifest.json` из исходной папки `src` или из собранных каталогов в папке `dist/qa/` / `dist/prod/`.

## 🛠 Технологический стек

* **Среда выполнения:** WebExtensions API (Firefox Gecko)
* **Интерфейс:** HTML5, CSS3 (адаптивная дизайн-система в стиле Tailwind CSS, поддержка Темной/Светлой темы)
* **Автоматизация:** Gulp, Terser, Clean-CSS, HTMLmin, Del
